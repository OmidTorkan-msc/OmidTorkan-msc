## **Selected Projects**

### [**Enhancing Sentiment Analysis**](https://github.com/OmidTorkan-msc/Thesis-Project)

Master’s thesis project focused on improving sentiment analysis through data augmentation and NLP techniques.

- Investigated the impact of injecting polarized terms into NLP workflows.
- Analyzed sentiment across **11 contract types**, including business, legal, and performance contracts.
- Implemented **VADER Sentiment Analysis** and data augmentation techniques.
- Evaluated model performance and analyzed sentiment trends before and after augmentation.
- Achieved **96.61% accuracy** and **0.9996 AUC** in the developed sentiment analysis workflow.

---

### [**Image Classification**](https://github.com/OmidTorkan-msc/Algorithm-For-Massive-Dataset)

Deep learning project for automated Turkish Lira banknote classification.

- Developed a **Convolutional Neural Network (CNN)** for image classification.
- Achieved **98% test accuracy**.
- Worked with a dataset of approximately **6,000 images**.
- Used image data generation techniques to efficiently process the dataset.

---

### [**Speech Emotion Recognition**](https://github.com/OmidTorkan-msc/Audio-Pattern-Recognition.git)

Machine learning project for speech emotion classification.

- Extracted audio features using **MFCC** and **Perceptual Wavelet Packets (PWP)**.
- Applied **SVM** and **KNN** classification algorithms.
- Worked with the **Berlin Emotional Speech Database**.
- Evaluated classification performance across different acoustic feature representations.

---

### [**Business Process Mining**](https://github.com/OmidTorkan-msc/BIS-Project)

Process mining project focused on discovering and analyzing business workflows.

- Preprocessed event logs to identify inefficiencies in business processes.
- Applied **Alpha Miner, Inductive Miner, and Heuristic Miner** algorithms.
- Generated process models from event-log data.
- Used heatmaps to identify bottlenecks and rework activities.

---

### [**Tkinter Appointment Scheduler**](https://github.com/OmidTorkan-msc/tkinter-appointment-scheduler)

Python desktop application developed as part of an **Apron Evals project at Outlier AI**.

- Refactored an initial script into a structured and maintainable Tkinter application.
- Implemented input validation for appointment title, date, time, and duration.
- Added **time-slot overlap detection and warnings**.
- Implemented automatic appointment sorting.
